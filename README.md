# Paulyn Joy Genodifa — Healthcare Portfolio

Modern minimalist pink personal portfolio website for GitHub Pages.

## Files
- `index.html` — complete website, including the embedded profile photo, animations, responsive layout, experience, specialties, tools, and contact section.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the live website URL.

No build tools, npm, or external assets are required.
